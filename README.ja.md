# ReplayNES

**ミスしたら戻って録り直す。最後に残るのは「ノーミスの通しプレイ」。**

ReplayNES は macOS 用のファミコン / NES エミュレーターです。プレイを動画ではなく
「入力の履歴」として記録するので、いつでも好きな場面まで巻き戻してそこから録り直せます。
録り終えたテイクを最初から再生すると、失敗した部分が消えたひと続きのプレイになります。
そのまま音声付き MP4 に書き出せます。

![ReplayNES のクイックメニュー（L+R または Esc。生成したテスト ROM の上）](docs/images/screenshot.png)

## 特徴

- **ROM ライブラリ**: `~/Documents/ReplayNES/ROM` に置いた ROM を一覧表示し、選ぶだけですぐに遊べます。プロジェクトは `~/Documents/ReplayNES/Projects` に自動で保存され、ROM ごとに「続きから」で再開できます。
- **フラッシュ低減（光の点滅への配慮）**: 画面全体が激しく点滅する場面を検出して、表示だけを抑えます（初期設定でオン）。ゲームの進行や記録には影響しません。
- **巻き戻しと録り直し**: どのフレームにも戻れます。そこから操作すると新しい試行（テイク）になり、前の試行も消えずに残ります。
- **練習モード（A/B リピート）**: 苦手な区間に A と B を付けて、録画せずに何度でも繰り返し練習できます。区間はプロジェクトごとに 8 つまで保存されます。
- **コントローラーだけで操作**: L+R 同時押しでクイックメニュー（ほかの機能はすべてここに。スクロールするページはありません。ボタンの割り当て変更もコントローラーだけでできます）、L2 で巻き戻し、R2 で早送り、R で一時停止、L でスロー。一時停止中は L / R と十字キーでコマ送りし、シークバーに A/B 練習のマーカーを置いて動かせます。ReplayNES が前面になくても（OBS を操作中でも）コントローラーが効きます。
- **テトリスのような乱数も完全に再現**: 再生は「ゲーム機の状態 + 毎フレームの入力」から計算し直すので、録画時とまったく同じ結果になります。
- **制作補助**: 一時停止、コマ送り、N コマ送り、1/2 スロー、タイムラインのシーク、ブックマーク、ソフトリセット、電源の入れ直し。どれも最終テイクの時間には含まれず、再生は常に正規速度です。
- **連射**: A/B の連射を周期と押下時間をフレーム単位で設定できます。記録されるのは連射を反映した後の入力です。
- **翌日に続きから**: プロジェクト（`.nesrec`）を保存すれば、後日開いたあとでもさらに過去へ巻き戻せます。自動保存とクラッシュからの復旧にも対応し、アプリを終了（強制終了を含む）しても次の起動時に自動で続きから再開します。
- **MP4 書き出し**: ゲーム内の時間を基準にオフラインで描き直すので、プレイ中のコマ落ちは動画に影響しません。ドットはニアレストネイバーで拡大し、オーバースキャンの切り取りとピクセル比（1:1 / 8:7）を指定できます。
- **低遅延**: Metal で表示し、オーディオのバッファは小さめです。遅延の計測表示（⌘L）もあります。
- **自動アップデート**: 新しいバージョンを GitHub Releases から確認し、署名（EdDSA）を検証してから更新します（[Sparkle](https://sparkle-project.org) を使用）。メニューの「ReplayNES → アップデートを確認…」からも確認できます。

## 動作環境

- macOS 14 以降、Apple Silicon（arm64）
- キーボード、または macOS が認識するゲームコントローラー（GameController.framework 対応）
- ゲームの ROM ファイル（`.nes`）は付属しません。ご自身が所有するソフトから合法的に用意したものを使ってください。

## インストール

1. [Releases](https://github.com/kathoc/ReplayNES/releases) から `ReplayNES-<version>-macOS-arm64.zip` をダウンロードして展開します。
2. `ReplayNES.app` を「アプリケーション」フォルダへ移します。
3. 公証（notarization）を受けていないため、初回は **右クリック →「開く」** で起動してください。それでも開けない場合は「システム設定 → プライバシーとセキュリティ」で「このまま開く」を選びます。
4. 2 回目の起動時に「アップデートを自動的に確認しますか？」と尋ねられます。以降の更新はアプリ内で行えます（0.1.2 以降。0.1.1 以前からは手動で入れ替えてください）。設定 › システム › アップデート で、自動確認と自動インストールをいつでもオン／オフできます。

## Steam Deck / Linux（プレビュー版）

ReplayNES は Steam Deck（SteamOS 3、ゲームモード / デスクトップモード）やその他の x86_64 Linux でも Flatpak（`io.github.replaynes.ReplayNES`）として動きます。プロジェクトも機能も同じです（ライブラリ、テイク付きの巻き戻しと録り直し、フィルムストリップのタイムライン、練習（A/B）、ブックマーク、自動保存と再開、フラッシュ低減、ブラウン管 (CRT) 表示、MP4 書き出し、英語 / 日本語）。詳しい説明: [docs/STEAM_DECK.md](docs/STEAM_DECK.md)（英語）。

1. **インストール**（デスクトップモードの Konsole）: `flatpak install --user https://kathoc.github.io/ReplayNES/flatpak/io.github.replaynes.ReplayNES.flatpakref` を実行します（GitHub Pages 上の署名付き ReplayNES リポジトリ。ランタイムは Flathub から取得されます）。または [Releases](https://github.com/kathoc/ReplayNES/releases) から `io.github.replaynes.ReplayNES-<version>-x86_64.flatpak` をダウンロードし、`flatpak install --user io.github.replaynes.ReplayNES-<version>-x86_64.flatpak` を実行します（同じリポジトリが登録されます）。読み取り専用の SteamOS 本体には何もインストールしません。**アップデート**: 新しいバージョンが出るとライブラリに「ReplayNES の新しいバージョンがあります。」と表示されます。設定 › システム › アップデート で「アップデート」→「再起動」、「今すぐ確認」ですぐに確認することもでき、`flatpak update` も使えます。ゲームモードではシステムが初回のアップデート許可を確認できないため、一度デスクトップモードでアップデートするか、`flatpak permission-set flatpak updates io.github.replaynes.ReplayNES yes` を実行してください（[詳細](docs/STEAM_DECK.md#updates)、英語）。
2. **Steam に追加**: デスクトップモードで Steam を終了してから ReplayNES を起動し、設定 › システム ›「**Steam に追加**」を選びます（または `flatpak run io.github.replaynes.ReplayNES --add-to-steam`）。カプセル・ヒーロー・ロゴ・アイコンのアートワーク付きで Steam ライブラリに追加されます（[詳細](docs/STEAM_DECK.md#add-to-steam-with-artwork)、英語）。Steam から追加する場合は Steam →「ゲーム」→「非 Steam ゲームをマイライブラリに追加…」→ ReplayNES にチェック。ゲームモードのライブラリから起動します（全画面で開きます）。OLED モデルでは 60 Hz（クイックアクセス →「パフォーマンス」）にすると動きがいちばん均一になります。
3. **ROM**: `.nes` ファイルを `~/Documents/ReplayNES/ROM` に入れます（デスクトップモードの Dolphin など）。起動画面はライブラリで、上に最新のプロジェクトの「続きから」カード、その下に大きなゲームのカードが並びます。A でプレイ（`~/Documents/ReplayNES/Projects` に新しいプロジェクト）、X でそのゲームのプロジェクト一覧、Y で検索。
4. **操作**（Steam Input の標準ゲームパッド設定）: 十字キー / 左スティック = ファミコンの十字キー、B / A = ファミコンの A / B、Y / X = 連射 A / B、メニュー / ビュー = START / SELECT、**L+R 同時押し = クイックメニュー、R = 一時停止（シークバー）、L = スロー 1/2、L2 長押し = 巻き戻し、R2 長押し = 早送り**。メニューでは **B（右）で決定、A（下）で戻る** です（設定 › 操作 › 決定ボタン で入れ替えられます）。
5. **クイックメニュー: L と R を同時に押す**（0.1 秒以内、どちらが先でも可。右上に常に出ている「☰ メニュー L+R」ピルのタップでも開きます）。ゲームが一時停止して暗くなり、6 つのタイルが並びます：再開、やり直す（ここから録り直す・前の試行へ・テイク一覧・ブックマーク・再生モード）、練習（8 つの A/B 区間をカードで）、共有（MP4 書き出し）、設定（画面 / 操作 / 音 / システム、L / R で切り替え）、ゲーム（ゲーム選択・保存・別名で保存・開く・リセット）。スクロールする画面はありません。選択中の項目は赤い枠で囲まれ、画面下に項目の説明が 1 行、右下に使っているコントローラーのボタンが出ます。

   | ボタン | プレイ中 | 一時停止中（シークバー） | メニュー内 |
   |---|---|---|---|
   | L+R 同時押し | クイックメニュー（一時停止） | クイックメニュー | 閉じる（再開） |
   | R だけ | 一時停止：シークバーだけが出ます | 1 コマ進む（押し続けると連続） | 次のページ |
   | L だけ | スロー 1/2 の切り替え | 1 コマ戻る（押し続けると連続） | 前のページ |
   | L2 / R2 長押し | 巻き戻し / 早送り（同じ速さで、どちらもだんだん速く） | 巻き戻し / 早送り | 巻き戻し / 早送り |
   | 十字キー / 左スティック | ファミコンの十字キー | ← / → コマ送り、↑ で A/B マーカーへ | 選択を動かす |
   | B（右） | ファミコンの A | A/B マーカーを置く | 決定 |
   | A（下） | ファミコンの B | **再開**（軽く押す） | 戻る（いちばん上では再開） |
   | Y / X | 連射 A / B | Y: 次の A/B 区間・X: 選んだマーカーを消す | 画面下のヒントの操作（名前変更、消去、検索、プロジェクト…） |

   L や R だけを押したときは**離したとき**に働くので、L+R の邪魔をしません。決定 / 戻るは 設定 › 操作 › 決定ボタン に従います（初期設定は B で決定。ゲームのボタンは変わりません）。一時停止中のボタンは「軽く押す」操作です：ボタン（たとえばダッシュの A）を押したまま → や R でコマ送りすると押した状態で進み、単独で軽く押したときだけ再開 / マーカーを置きます。プレイ中のメニュー（≡）は START のままです（ゲームで必要なため）。タッチやトラックパッドでもすべての画面を操作できます。

   **文字入力（検索、名前）**: 入力欄を選ぶとスクリーンキーボードが出ます。ゲームモードでは Steam のキーボードを呼び出します（日本語を入力できます）。表示されないときは決定ボタンを押すと ReplayNES 内蔵のコントローラー用キーボードに切り替わります（決定で入力、戻るで削除、X スペース、Y シフト、L1 / R1 カーソル移動、ビュー（⧉）記号、メニュー（≡）完了）。設定 › 操作 ›「画面キーボード」で 自動 / 内蔵 / Steam を選べます。

日本語の表示にはシステムの CJK フォントを使います（SteamOS には入っています）。プレイ中に表示するのはメニューピルだけで（ゲームと同じ描画パス内）、遅延は増えません。

## Windows（プレビュー版）

ReplayNES は Windows 10 / 11（x64 と ARM64）でも、インストール不要のアプリとして動きます。画面と機能は Steam Deck / Linux 版と同じです：ライブラリ、テイク付きの巻き戻しと録り直し、フィルムストリップのタイムライン、練習（A/B）、ブックマーク、自動保存と再開、フラッシュ低減、ブラウン管 (CRT) 表示、MP4 書き出し、英語 / 日本語、画面に同期した低遅延の進行（Direct3D 11）。詳しくは [docs/WINDOWS.md](docs/WINDOWS.md)。

1. **インストール**：`ReplayNES-<version>-windows-x64.zip`（Windows on Arm は `-arm64`）を、書き込みできるフォルダー（ユーザーフォルダーの中など。`Program Files` ではなく）に展開して `ReplayNES.exe` を起動します（インストーラーはありません。隣の `WinSparkle.dll` はアップデート用です）。まだコード署名していないため、初回に SmartScreen が確認することがあります（「詳細情報」→「実行」）。
2. **ROM**：`.nes` ファイルを `ドキュメント\ReplayNES\ROM` に入れます（ライブラリの「フォルダを開く」でエクスプローラーが開きます）。「プレイ」で `ドキュメント\ReplayNES\Projects` にプロジェクトが作られます。一時セッションは `%LOCALAPPDATA%\ReplayNES\Session`、設定は `%APPDATA%\ReplayNES` にあります。プロジェクトのリセットや「別名で保存」で置き換えたプロジェクトはごみ箱に移ります。
3. **操作**：Xbox 系コントローラー（XInput / GameInput）、PlayStation、Switch Pro コントローラーに対応し、割り当ては Steam Deck 版と同じです（位置で A = NES の B、B = NES の A、メニュー / ビュー = START / SELECT、L+R 同時押し（LB+RB、L1+R1）= クイックメニュー、R = 一時停止、L = スロー、L2 / R2 長押し = 巻き戻し / 早送り）。キーボードは矢印、X / Z、Enter、右 Shift、Space 一時停止、Backspace 巻き戻し、Tab 早送り、Esc / F1 クイックメニュー、F11 全画面。コントローラーがなくても右上の「☰ メニュー Esc」ピルをクリックで開けます。すべて設定で変更できます。
4. **表示**：F11 か 設定 › システム › 詳細 › フルスクリーン（ボーダーレス）。G-SYNC / FreeSync のディスプレイでは `ReplayNES.exe --vrr` で、全画面時にテアリングを許可して NES 本来の 60.0988 Hz で表示します。設定 › 画面 ›「ブラウン管」で物理モデルの CRT 表示になります（Direct3D 11 の計算シェーダー。Direct3D 11.0 対応 GPU が必要です）。
5. **MP4 書き出し**：クイックメニュー › 共有 ›「MP4書き出し」（Windows の Media Foundation による H.264 + AAC。GPU にハードウェアエンコーダーがあればそれを使います）。`ドキュメント\ReplayNES\Exports` に保存されます。
6. **アップデート**：2 回目の起動時に確認されたとき許可すると、1 日 1 回 GitHub で新しいバージョンを確認します。設定 › システム › アップデート ›「今すぐ確認」ですぐに確認することもできます。アップデートはダウンロード後に署名を確認してからインストールされ、ReplayNES は新しいバージョンで再起動します（セッションは先に保存されます）。「自動で確認」をオフにすると毎日の確認を止められます。

## 使い方

### 画面

ReplayNES のウインドウは 1 つです。プレイ中はゲーム画面と、右上の小さな **「☰ メニュー L+R」** ピルだけが表示されます（コントローラーがないときは「Esc」、PlayStation のコントローラーでは「L1+R1」）。それ以外の機能はすべて **クイックメニュー** とメニューバーにあります。

- **ライブラリ**（起動画面、ゲーム › ゲーム選択… ⇧⌘L）: 下の「ライブラリ」を参照。
- **クイックメニュー**: **L と R を同時に**押す（0.1 秒以内、順不同）、**Esc** を押す、またはピルをクリックします。ゲームは一時停止し、暗くなった画面の上に 6 つのタイルが並びます。もう一度 L+R / Esc（または「再開」）で続きをプレイします。
- **一時停止（R / Space / ⌘P）**: 画面下に時間付きのフィルムストリップのシークバーだけが出ます。ゲーム画面を覆うものはほかにありません。
- **メニューバー**: ゲーム（ライブラリ、新規 / 開く / 保存、リセット、閉じる）、やり直す、練習、共有、表示（FILL ⌘F、フルスクリーン ⌃⌘F、レイテンシ表示 ⌘L）、ウインドウ（閉じる ⌘W）、ヘルプ › 操作（⌘?）。⌘, でクイックメニューの設定を開きます。

### クイックメニュー

| タイル | 中身 |
|---|---|
| **再開** | メニューを閉じてプレイを続ける（メニューを開いたときのフォーカス） |
| **やり直す** | ここから録り直す・前の試行へ（⌥⌘Z）・見返す / 録画に戻る（⇧⌘M）・テイク一覧（⇧⌘T）・ブックマーク |
| **練習** | 8 つの A/B 区間のカード（「練習モード」を参照） |
| **共有** | MP4に書き出す（⌘E）・配信出力（Syphon、OBS 用） |
| **設定** | 4 ページを L / R（または Tab）で切り替え: **画面**（サイズ 等倍 / FILL、ブラウン管、8:7、点滅を抑える、端を隠す、ブラウン管の詳細）、**操作**（コントローラーの図、キーボード、決定ボタン、一時停止中の十字キー、巻き戻し後に一時停止、操作の詳細）、**音**（音量）、**システム**（言語、自動保存、遅延の表示、点滅抑制の表示、アップデート、バージョン情報） |
| **ゲーム** | ゲーム選択・保存・別名で保存・リセット（ソフトリセット、電源再投入、最初からやり直す）・閉じる |

スクロールするページはありません。1 ページの項目は最大 6 つで、長い一覧（テイク、ブックマーク、キーの割り当て）は L / R で切り替えるページに分かれます。フォーカス中の項目は赤い枠で示され、下の 1 行にその説明が、右下にお使いのコントローラーのボタン（またはキー）が表示されます。マウスやトラックパッドもどこでも使えます。

| ボタン | プレイ中 | 一時停止中（シークバー） | メニュー内 |
|---|---|---|---|
| L+R 同時 / Esc | クイックメニュー（一時停止） | クイックメニュー | 閉じる（再開） |
| R 単独 | 一時停止（シークバー） | 1 コマ進む（押し続けると連続） | 次のページ |
| L 単独 | スロー 1/2 のオン / オフ | 1 コマ戻る（押し続けると連続） | 前のページ |
| L2 / R2 長押し | 巻き戻し / 早送り（同じ速さ） | 巻き戻し / 早送り | — |
| 十字キー / 左スティック | ファミコンの十字キー | ← / → コマ送り、↑ で A/B マーカーへ | フォーカスの移動 |
| 右のボタン（Xbox の B、Nintendo の A、○） | ファミコンの A | A/B マーカーを置く | 決定 |
| 下のボタン（Xbox の A、Nintendo の B、✕） | ファミコンの B | **再開**（軽く押す） | 戻る（最上位では閉じる） |
| Y / X | 連射 A / B | Y: 次の A/B 区間・X: 選んだマーカーを消す | ヒントバーに出ている操作（名前の変更、消去、検索、プロジェクト…） |

キーボード: Esc でクイックメニューの開閉、Space で一時停止 / 再開。メニュー内では矢印で移動、Return / Space で決定、Delete で戻る、Tab / ⇧Tab でページ切り替え。L や R の単独押しは離したときに働くので、L+R の邪魔をしません。設定 › 操作 › 決定ボタン でコントローラーの決定（右）と戻る（下）を入れ替えられます。クイックメニューは割り当てを変えられる操作です（設定 › 操作 › キーボード）。初期設定はパッド 1 の L+R と Esc です。

### ライブラリ

ReplayNES は起動時に次のフォルダを作ります（初回は macOS が「書類」フォルダへのアクセス許可を求めるので、「許可」を選んでください）。

| フォルダ | 中身 |
|---|---|
| `~/Documents/ReplayNES/ROM` | ご自身の ROM（`.nes`）を入れる場所。1 階層下のサブフォルダも読み込みます |
| `~/Documents/ReplayNES/Projects` | ライブラリから始めたプロジェクト（`<ROM名> <yyyy-MM-dd HHmm>.nesrec`）の保存先 |

- 上の大きな **「続きから」** カードで、最新のプロジェクトを前回の続きから開けます。その下に大きなゲームカード（最新のプロジェクトのサムネイル）が並び、スクロールの代わりに L / R でページを切り替えます。
- **A / Return / ダブルクリック** でフォーカス中のゲームをプレイします。保存先を聞かれずに新しいプロジェクトが作られ、すぐにゲームが始まります。作業は自動で保存されます。
- **X** でそのゲームのプロジェクト一覧（「新しく始める」で別のプロジェクトを作成）。プロジェクトと ROM の対応は ROM の中身（SHA-256）で判定するので、ROM のファイル名を変えても対応は保たれます。**Y** で検索。ROM がまだないときは、入れる場所を示すカードが 1 枚出ます（「フォルダを開く」）。追加・削除は自動で反映されます。
- ゲームメニュー: 新規プロジェクト…（⌘N: 保存先を選ぶ）、プロジェクトを開く…（⌘O）、ROMを開いて試す（プロジェクトなし）…（⇧⌘N: プロジェクトを作らずに遊ぶ。次の起動時に続きから再開）。
- ゲーム中に別のゲームを選ぶと、保存していない変更があれば保存するか確認します（下の「再開」を参照）。

### 録画と見返し

- ReplayNES はゲームが始まった瞬間から録画します。**やり直す › 見返す**（⇧⌘M）は録画済みのテイクを録画せずに再生します。テイクの終端にいたときは先頭から、そうでなければいまの位置から再生し、終端で一時停止します。
- **やり直す › 録画に戻る**（または「ここから録り直す」）で、その位置の録画モードに戻ります。次の入力から続きが録画されます。途中の位置なら新しいテイクに分岐し、元の続きも残ります。
- **サイズ**: 「等倍」は画面に収まる最大の整数倍で、ドットがくっきり揃います。「FILL」は縦横比（4:3、またはピクセル比 8:7）を保ったままウインドウいっぱいに広げます。設定 › 画面 › サイズ、または 表示 › FILL（⌘F）で切り替え、設定は保存されます。
- **シークバー（フィルムストリップ）**: プレイ 5 秒ごとに 1 枚のスクリーンショットが本来の大きさで並びます（テイクが伸びると 10 秒、20 秒…に 1 枚）。ドラッグでその位置へ移動（無音・一時停止）。再生位置（録画中は赤、再生中は白、練習中はオレンジ）、ブックマーク（黄）、A/B 区間（番号付きの色の帯）が重ねて表示されます。サムネイルはゲームとは別に（テイクのチェックポイントから並列に）作られるので、1 時間のテイクでも開いて少し待つだけで表示されます。

### フラッシュ低減（光の点滅への配慮）

爆発や稲妻などで**画面の広い範囲が激しく点滅する場面**を検出し、表示する映像だけを抑えます（明滅の回数を減らし、暗い側で保ちます）。WCAG 2.x の一般閃光・赤色閃光の基準（画面の約 25% 以上が 1 秒に 3 回を超えて明滅しない）を目安にしています。

- 設定 › 画面 › **点滅を抑える** で **オフ / 弱 / 標準 / 強** を選べます。初期設定は **標準（オン）** です。
  - 弱: WCAG の基準どおり（1 秒に 3 回まで）
  - 標準: 早めに検出し、1 秒に 2 回まで（推奨）
  - 強: 1 秒に 1 回まで。小さな残りのちらつきも弱めます
- 小さな点滅（キャラクターの点滅など）や通常のスクロールはそのまま表示します。抑えている間は画面左上に「フラッシュ低減中」と表示されます（設定 › システム › 点滅抑制の表示 で非表示にできます）。
- 記録される入力・ゲームの進行・再現性（ハッシュ）には一切影響しません。表示だけの処理です。
- MP4 書き出しでは「フラッシュ低減を適用」を選ぶと、書き出す映像にも適用できます（初期値は現在の設定に従います）。

> **注意**: この機能は光過敏性発作などを確実に防ぐものではありません。点滅に敏感な方は十分に注意し、体調に異変を感じたらすぐにプレイを中止してください。仕組みと限界は [docs/FLASH_REDUCTION.md](docs/FLASH_REDUCTION.md) を参照してください。

### コントローラーとキーの割り当て

コントローラーのボタンは**位置**で割り当てています（右のボタン = ファミコンの A、下のボタン = B）。Nintendo のコントローラーでは印字どおり A = A、B = B になります。

| 操作 | コントローラー（位置） | Proコン / Joy-Con | Xbox | PlayStation | キーボード |
|---|---|---|---|---|---|
| 十字キー | 十字キー / 左スティック | | | | ← ↑ → ↓ |
| A / B | 右 / 下のボタン | A / B | B / A | ○ / ✕ | X / Z |
| 連射 A / 連射 B | 上 / 左のボタン | X / Y | Y / X | △ / □ | S / A |
| START / SELECT | Menu / Options | + / − | ≡ / View | OPTIONS / CREATE | Return / 右 Shift（または `\`） |
| クイックメニュー | **左右のショルダーを同時に** | L + R | LB + RB | L1 + R1 | Esc |
| 巻き戻し（押している間） | **左トリガー** | ZL | LT | L2 | Delete |
| 早送り（押している間） | **右トリガー** | ZR | RT | R2 | Tab |
| 一時停止 / 再開 | **右ショルダー** | R | RB | R1 | Space |
| スロー 1/2 ⇔ 等速 | **左ショルダー** | L | LB | L1 | L |
| 一時停止中のコマ戻し / コマ送り | **L / R** か **十字キー ← / →**（押し続けると連続） | | | | `,` / `.` |
| ブックマーク | — | | | | B |

- **設定 › 操作 › コントローラー** に、接続中のコントローラーの図（Steam Deck / Nintendo / Xbox / PlayStation / その他の形）と各ボタンの割り当てが表示されます。ボタンを押すと図の上で光ります。コントローラーだけで操作できます：十字キーかスティックで赤い枠をボタンに合わせて決定し、6 つずつのページ（L / R でページ送り、戻るで取り消し）から動作（ファミコンのボタン・連射・ホットキー・なし）を選びます。X でパッドを切り替え、Y でそのパッドを初期設定に戻します。**キーボード** はすべての操作とそのキーの一覧です（決定のあと新しいキーを押す。戻る / Esc で取り消し、X で消去）。**操作の詳細**: 逆方向の同時押し（←+→）、スティックのしきい値、連射の押す長さ、割り当てを既定に。
- 巻き戻し・早送り・一時停止・スロー・コマ送り・クイックメニューは「ホットキー」で、ゲームへの入力として記録されることはありません。
- **一時停止中**は L / R と十字キー ← / → でコマ送り / コマ戻しをし（ゲームには送られません。十字キーの分は 設定 › 操作 › 一時停止中の十字キー でオフにできます）、**戻るボタン（A / 下）を軽く押すと再開**します。ほかのボタンはそのままゲームに届くので、ボタン（たとえばダッシュの B）を押したまま → でコマ送りすると、押した状態でフレームを進められます。コマ送りをはさんで押し続けたボタンでは再開もマーカー置きもしません。
- **早送り**は録画済みのテイクを高速で再生するだけで、何も録画しません。録画済みの終端で止まって一時停止します。
- **バックグラウンド入力**: コントローラーが接続されていれば、ReplayNES が前面にないとき（OBS を操作中など）も入力を受け付け、音も鳴り続けます。キーボードは ReplayNES が前面のときだけ有効です。コントローラーが外れると一時停止します。
- **古いバージョンからのアップデート**: 保存された割り当ては一度だけ、変更していない部分に限って更新されます。0.1.x のコントローラーのホットキー → 現在のもの。0.2.x まではトリガーが逆（R2 巻き戻し）。0.2.0 までは Nintendo のコントローラーで A / B と X / Y が逆（変更していた顔ボタンはそのコントローラーを接続したときに引き継がれます）。0.5.0 でクイックメニュー（パッド 1 の L+R と、まだ何も割り当てていなければ Esc）が加わります。R は一時停止、L はスローのままです。新しいバージョンがクイックメニューを加えた割り当てファイルは、古いバージョンでは読めません。

### 巻き戻しと録り直し

1. ミスしたら **L2（または Delete）を押し続けて巻き戻す**か、シークバーをドラッグして戻ります。
2. そこからプレイを続けると、その位置から新しいテイクが録画されます。元の続きは消えずに残ります。
3. 前のテイクのほうが良かった場合は **やり直す › 前の試行へ**（⌥⌘Z）で戻せます。**やり直す › テイク一覧**（⇧⌘T）にすべてのテイクが並び、選ぶとそのテイクに切り替わります。
4. **ブックマーク**（B / ⌘D、または やり直す › ブックマーク › ここに追加）で場面に印を付けられます。ブックマークを選ぶとその位置へ移動します（Y で名前の変更、X で削除）。

**ゲーム › リセット › 最初からやり直す**（ゲームメニュー: 最初からやり直す…）は、プロジェクトを電源投入から空のタイムラインでやり直します。すべてのテイク、ブックマーク、テイクの履歴が削除されます。ROM とプロジェクトの保存場所は変わりません。「A/Bリピート区間を残す」（初期設定でオン）を選ぶと練習用の区間は残ります。保存済みのプロジェクトは先にバックアップがゴミ箱に移されるので、元の録画をそこから取り戻せます。

### 制作補助

- 一時停止（R / Space / ⌘P）、コマ送り（一時停止中の十字キー → / `.` / ⌘→）、コマ戻し（十字キー ← / `,` / ⌘←）、1 秒戻る / 進む（⌘[ / ⌘]）、先頭へ（⌘↑）。
- スロー: 1/2 ⇔ 等速（L / ⌘2）。スローや一時停止は最終テイクの時間に含まれません。
- ソフトリセット（⌘R）と電源再投入（⇧⌘R）（ゲーム › リセット）は、どのフレームで行ったかが記録され、再生時にも同じフレームで再現されます。
- 一時停止中、巻き戻し中、シーク中、スロー中、早送り中は音が出ません。

### 練習モード（A/B リピート）

苦手な区間だけを、録画せずに何度でも繰り返し練習できます。

1. **クイックメニュー › 練習**（⇧⌘P）を開くと、8 つの区間がカードで並びます。区間の始まりで、空いているカードの **「ここをAに」** を選びます。
2. そのカードを選ぶと A から練習が始まります。区間の終わりまでプレイしたらメニューを開き、そのカードの **「Bを設定」** を選びます（練習の外では、A から続けてプレイして 練習 › ここをBに（タイムライン）⌥⌘O）。各区間には長さ（分:秒.フレーム）が表示されます。Y で名前の変更、X で消去。
3. 完成した区間を選ぶと **練習** が始まります。A から自動でプレイが始まり、**B に着くと 0.5 秒その画面のまま止まり（音は自然に消えます）、巻き戻るように A へ戻って、また自動で始まります**。
4. 練習中も L2 の巻き戻し（A まで）、R の一時停止、L のスロー、一時停止中の十字キーのコマ送り / コマ戻しが使えます。
5. **「練習をやめる」**（練習中のカード、または ⇧⌘P）で、練習を始める前のテイクの位置に正確に戻ります。

- 練習中は何も録画されません。テイクは変わりません。
- B は「A から続けてプレイした位置」で設定してください。A の後に巻き戻し・シークバーでの移動・テイク切り替えをした場合は、その旨が表示されます（A からやり直すか、A を設定し直してください）。
- 区間はプロジェクトに保存されます（自動保存にも含まれます）。区間のデータが壊れていた場合は、開くときに「壊れた練習区間を破棄して開く」を選べます（テイクは影響を受けません）。
- 練習中はシーク、ブックマーク、テイク切り替えは使えません。

#### シークバーで A/B を指定する

録画済みのテイクなら、プレイし直さずに区間を決められます。一時停止中のシークバーには A/B 区間の帯と、右端に区間の選択（「A/B 1」）があります。

- 帯の上を**ドラッグ**すると、その範囲が選択中の区間の A→B になります（サムネイル上では **Shift+ドラッグ**）。区間の**両端をドラッグ**すると A / B を調整でき、**区間をクリック**するとその区間の練習が始まります。
- 再生位置で **練習 › ここをAに（タイムライン）**（⌥⌘I）/ **ここをBに（タイムライン）**（⌥⌘O）。B は、A がこのテイク上にあれば、A から続けてプレイしていなくても設定できます。
- 表示されるのは、いまのテイク上にある区間だけです。区間の設定は練習中にはできません。
- **コントローラーでは**（一時停止中）：選んでいる区間（「A/B 1」、Y で次へ）がシークバー上の旗で表示されます。決定（B / 右）で再生位置に旗を置きます。1 本目が A、2 本目で区間になります（左の旗が A、右が B）。↑ で旗へ移り（← / → で選ぶ、↓ か戻るでシークバーへ）、旗の上で決定すると動かせます：← / → で 1 コマ、L / R 長押しで巻き戻し / 早送りと同じ速さで動き、画面も付いてきます。決定で確定、戻るで元に戻します。もう一方の旗を追い越すと A と B が入れ替わります。X で選んだ旗を消します（2 本のうち 1 本を消すと「A だけ」の区間になります）。

### 翌日に続きから

**ゲーム › 保存**（⌘S）で保存し、後日 **プロジェクトを開く**（⌘O）、ライブラリの「続きから」カード、またはゲームのプロジェクト一覧（X）から開くと、最後に使っていたテイクの続きから再開でき、さらに過去へ巻き戻すこともできます。作業中は自動保存されます（初期設定は 2 秒ごと。設定 › システム › 自動保存。一時停止したときとアプリが裏に回ったときにもすぐ保存します）。プロジェクトを開いたときに前回の異常終了が見つかった場合は、最後の自動保存まで復旧され、その旨が表示されます。

### 再開（終了しても続きから）

- **自動で続きから**: ⌘Q やウインドウを閉じて（⌘W）終了するときに「保存しますか？」とは聞かれません。作業中の内容はそのまま残り、次に起動すると前回のプロジェクト（またはプロジェクトなしで遊んでいたセッション）が**前回の位置・モードで一時停止した状態**で開き、「前回の続きから再開しました」と表示されます。強制終了や停電の場合も、最後の自動保存（数秒以内）の位置から再開します。
- **プロジェクトの場合**: 終了時はプロジェクトの自動保存（ジャーナル）に書き込むだけで、⌘S で保存した内容は変わりません。別のプロジェクトや ROM に切り替えるときは、保存するか確認します（「保存しない」を選ぶと最後に保存した状態に戻ります）。
- **一時保存の場所**: プロジェクトを作らずに遊んだとき（ROMを開いて試す、ROM ファイルを直接開いたとき）の作業は `~/Library/Application Support/ReplayNES/Session/current.nesrec` に保存されます（再開情報は同じフォルダの `resume.json`）。ライブラリの「続きから」には表示されません。⌘S で好きな場所に保存すると通常のプロジェクトになります。
- **破棄されるタイミング**: 一時保存に録画した内容があるまま別の ROM / プロジェクトを開こうとすると「保存しますか？」と聞かれます。「保存…」でプロジェクトとして残り、「保存しない」で破棄されます（ゲーム › 閉じる も同様）。何も録画していない一時保存は聞かずに破棄されます。
- **再開できなかったとき**（ROM の移動・削除、別のコア、ファイルの破損）: 理由を表示してライブラリに戻ります。ROM を指定し直せる場合はその場で指定できます。一時保存は**削除せずに残し**、次の起動時にもう一度再開を試みます。
- ReplayNES を 2 つ同時に起動した場合、あとから起動した方は再開せず、一時保存にも触れません。

ROM ファイルの場所を移した場合は、開くときに ROM を指定し直してください（SHA-256 で同じ ROM であることを確認します）。**ROM 本体はプロジェクトには保存されません。**

### MP4 に書き出す（⌘E）

クイックメニュー › 共有 › MP4に書き出す、またはメニューバーの 共有 › MP4に書き出す…。

- 形式: H.264 または HEVC と AAC（48 kHz）
- サイズ: 256×240 の整数倍、1280×960、1920×1440 など
- オーバースキャンの切り取りと、ピクセル比 1:1 / 8:7 を選べます。
- 「フラッシュ低減を適用」で、激しい点滅を抑えた映像にできます（上の「フラッシュ低減」を参照）。
- 書き出しは別のエミュレーターで最初から計算し直します。書き出しによってプロジェクトが変わることはなく、書き出し中も作業を続けられます。

### 配信 (OBS)

ゲーム画面を [Syphon](https://syphon.github.io) で出力し、OBS などの配信ソフトに直接取り込めます（仮想カメラではありません）。

1. ReplayNES で **クイックメニュー › 共有 › 配信出力** を開いてオンにします（メニューバーの 共有 › 配信出力 (Syphon) でも切り替えられます）。オンの間はゲーム画面の左上に「Syphon出力中」と表示されます。
2. OBS（macOS 版）で「ソース → ＋ → Syphon クライアント」を追加し、サーバーに「[ReplayNES] ReplayNES」を選びます。
3. 音声は OBS の「macOS 音声キャプチャ」ソース（アプリケーションの音声をキャプチャ）を追加し、ReplayNES を選びます。ReplayNES 側の設定は不要です。

- 出力されるのはゲーム画面だけです（UI、ピル、バッジは含みません）。フラッシュ低減は表示と同じく適用済みで、オーバースキャン部分も含む 256×240 全体を最近傍補間で拡大します。
- 配信出力のページで、サイズ（原寸 256×240、2〜4 倍（既定は 4 倍 1024×960）、黒帯付きの 1280×960 / 1920×1440）、ピクセル比 8:7、ブラウン管の映像を配信するかを選べます（表示の設定とは別）。
- 出力はエミュレーションとは別のスレッドで行い、受け取る側がいないときは描画もしません。OBS 側で数フレーム程度の遅延が出ることがあります。
- 一時停止中は最後の画面が表示され続けます。
- コントローラーは ReplayNES が前面になくても効くので、OBS を操作しながらでもそのままプレイできます。

## コアの互換性について（重要）

録画データは「どのエミュレーターコアで再生するか」に強く依存します。コアのバージョンが少しでも違うと、同じ入力でも結果がずれることがあります。
そのため各プロジェクトには、作成したときのコア互換 ID（例: `nestopia-ue@7b5c87d8dc3c+p2+adapter1+ntsc`）が記録されています。

- 互換 ID が違うプロジェクトは、**警告なしには開きません**。黙って変換することもありません。
- 将来のバージョンで互換 ID が変わった場合は、旧コアを同梱するか、明示的に移行する手順を用意します（[docs/COMPATIBILITY.md](docs/COMPATIBILITY.md)）。
- 大事なプロジェクトは、作成に使ったバージョンの ReplayNES と一緒に保管することをおすすめします。

## プライバシー

ReplayNES がネットワークに接続するのは、アップデートの確認とダウンロードのために GitHub（github.com とそのダウンロード用サーバー）へアクセスするときだけです。
送るのは更新情報（`appcast.xml`）と更新ファイルを取得する通常の HTTPS リクエストだけで、システム情報・使用状況・ROM やプロジェクトの内容は一切送信しません。テレメトリもありません。

- 自動確認は、2 回目の起動時に表示される確認で許可した場合だけ有効になります（macOS と Windows。Windows 版は `appcast-windows.xml` を取得します）。
- 設定 › システム › アップデート で自動確認をオフにすると、メニューから手動で確認したとき以外は接続しません。

読み書きするのは、指定した ROM とプロジェクト、ライブラリのフォルダ（`~/Documents/ReplayNES`）、設定ファイル、それにアップデート用のキャッシュだけです。

## 既知の制限

- 対応しているのは NTSC（日本 / 北米）のタイミングだけです。PAL とディスクシステム（FDS）は検証していません。
- 決定論テスト（同じ入力から同じ結果になるか）は、付属の自作テスト ROM で行っています。市販ソフトで使われる多くのマッパーは個別には検証していません。問題に気づいたらお知らせください。
- 自動保存は、エミュレーションのフレームの合間に実行されます。遅いディスクではまれに 1 フレーム遅れることがあります。
- 音声はタイマーとオーディオクロックのずれを、サンプルを間引いて吸収しています。まれにプチッとノイズが入ることがあります。スロー中と早送り中は音が出ません。書き出す音声はモノラルです。
- 画素がぴったり揃った整数倍の拡大になるのは、ピクセル比 1:1 のときだけです。8:7 では横方向の拡大幅が均一になりません。
- UI は英語と日本語に対応しています（システムの言語設定に従います）。動作確認は Apple Silicon でしか行っていません。実機のゲームコントローラーでの確認は限られています。
- 公証を受けていないため、初回の起動に手順が必要です（[インストール](#インストール)を参照）。
- Steam Deck / Linux 版と Windows 版はプレビュー版です（[Steam Deck / Linux](#steam-deck--linuxプレビュー版)、[Windows](#windowsプレビュー版) を参照）。Windows 版はまだ VM でのみテストしています（実機 PC の GPU やフレームペーシングは未計測です）。

## ソースからビルド

```bash
git clone --recursive https://github.com/kathoc/ReplayNES.git
```

```bash
cd ReplayNES && scripts/build-macos.sh
```

必要なもの: Xcode 16 以降、CMake、Ninja、XcodeGen（`brew install cmake ninja xcodegen`）。初回のビルドで Swift Package Manager が Sparkle を取得します。Syphon はサブモジュール `third_party/syphon` からソースでビルドされます（Metal Toolchain の追加ダウンロードは不要）。`scripts/check-syphon-macos.sh` で配信出力を OBS なしで確認できます。

エンジンとテスト（macOS / Linux / Windows 共通）は次のとおりです。

```bash
cmake -G Ninja -S . -B build -DCMAKE_BUILD_TYPE=Release && ninja -C build && ctest --test-dir build
```

Windows 向けには、アプリ（`ReplayNES.exe`、ターゲット `replaynes-win`。SDL3 はサブモジュール `third_party/SDL` から）・エンジン・フロントエンドコア・テストを MSVC / clang-cl でビルドするか（`cmake -S . -B build && cmake --build build --config Release`）、Mac 上で llvm-mingw によりクロスビルド（`scripts/build-windows.sh`。`dist/ReplayNES-<version>-windows-{x64,arm64}.zip` も作ります）して Windows VM で実行できます。詳しくは [docs/WINDOWS.md](docs/WINDOWS.md) を参照してください。Linux 版と Windows 版は UI とフレームループを共有しています（`apps/desktop`）。

コマンドラインツール `replaynes-cli` で、決定論の検証（`determinism`）、プロジェクトの検証（`verify`）、テスト ROM の生成（`make-test-rom`）などができます。

設計については [docs/ARCHITECTURE_DECISION.md](docs/ARCHITECTURE_DECISION.md)、ファイル形式は [docs/FILE_FORMAT.md](docs/FILE_FORMAT.md)、他の OS への移植は [docs/PORTING.md](docs/PORTING.md) を参照してください。
